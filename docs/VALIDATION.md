# MVP 验证结果

验证环境：Windows，Node.js v22.17.0，npm 10.9.2。日期：2026-09-08。

## 已通过

- TypeScript 严格类型检查：`npm run check`。
- 生产构建：`npm run build`。
- Node 测试：12 项通过，0 项失败（`node --test backend/tests/*.test.js`，与 `npm test` 执行内容相同）。
- npm 安装审计结果：162 个包，0 个已报告漏洞。
- `npm start` 实际启动；首页、健康检查和歌曲接口 HTTP 200。
- `npm run dev` 实际启动；前端构建监听与后端监听都运行，源码修改触发成功重建。
- `git diff --check` 无空白错误。

## 测试覆盖

1. 离线模式不调用外部 AI。
2. AI 多段文本解析和空响应错误。
3. 注册、密码哈希、登录、退出和旧会话失效。
4. 内容验证、非法 JSON、跨站请求和未知接口。
5. 推荐筛选、收藏幂等和账户隔离。
6. 草稿与聊天历史的私有性；写词请求不混入聊天历史。
7. 社区发布、重复点赞、评论、公开读取及危险音频 URL 拒绝。
8. 练习时长与 BPM 验证、个人统计。
9. AI 上游故障显式返回错误，不伪造回复或污染历史。
10. 模型只收到服务端历史，密钥不出现在 API 响应。
11. 登录请求限流。
12. SQLite 关闭后重新打开，数据仍保留。

## 验证边界

未提供真实模型密钥，未测试真实模型网络连通性、计费或生成质量；上游请求使用模拟响应。未做浏览器自动化回归、音频听感测量和外部音乐网站可用性测试。前端已经编译并通过静态类型检查；实际点击与音频验收步骤见 START.md。

当前环境中 Vite 开发预处理扫描上级目录受限。因此默认开发命令采用 Vite 构建监听 + Node 监听的同源运行方式；修改前端后需要刷新浏览器，没有热更新。生产构建和运行均已验证。

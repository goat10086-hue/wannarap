## 已实施范围

- React + TypeScript + Vite：发现音乐、AI 对话、写词、练习、社区、个人空间六个视图；响应式深色界面、加载/空白/错误状态。
- Node.js + Express：验证输入、限流、登录鉴权、同源写入限制、HTTP-only Cookie 会话；密码以独立随机盐 scrypt 哈希保存，数据库只存会话令牌摘要。
- SQLite：用户、会话、歌曲收藏、私有草稿、聊天历史、帖子、点赞、评论和练习记录。启动自动创建表，重启保留数据。
- 歌曲发现：6 首人工精选曲目，按心情和风格筛选，搜索与收藏；推荐理由为编辑文案，不冒充模型推荐。
- AI：服务端调用 Responses API，密钥不会发送到前端。带最近 12 条历史；独立写词请求不污染聊天历史。未配置密钥时显式离线模板模式，配置后的失败返回错误而不是暗中切换模板。
- 音乐播放：浏览器选择并播放本地音频，不上传文件；精选商业歌曲通过外部平台搜索入口收听，不提供未获授权的音源。
- Rap 练习：Web Audio 节拍器、60–160 BPM、4/4 拍、练习主题、计时和持久化累计记录。练习 5 秒以上可保存。
- 社区：发布 Verse / Demo / 心得，选填 HTTPS 音频直链；点赞与评论，登录后可写，访客可读。

## 实现取舍和待办

原文档规划 NestJS、Tailwind 和 PostgreSQL。为了首版在仅安装 Node.js 的电脑运行，当前使用 Express、独立 CSS 和 SQLite，避免引入外部数据库服务。目录边界已保留，后续可以迁移，不宣称已实现原规划中的全部基础设施。

这是本地功能验证 MVP。尚未实现音频上传/对象存储、录音、声学评分、推荐学习算法、AI 工具调用和长期记忆、找回密码、邮箱验证、社区举报管理、分页加载以及线上部署。社区当前最多返回最近 100 篇作品，每篇最多显示 100 条评论。

上线前应补充 HTTPS、账号恢复、社区管理和数据备份，并根据负载将数据库和限流迁移到适合多实例部署的服务。不要在源码中放置密钥。

无真实 API 密钥时，测试使用模拟上游响应验证解析、历史传递和失败处理，不能替代真实模型连通性或生成质量测试。
